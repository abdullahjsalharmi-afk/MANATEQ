# مناطق ون · Manateq One

**خمسون خدمة. رحلة واحدة.**

نموذج تجريبي عالي الدقة لتطبيق خدمات المستثمرين في «مناطق» (شركة المناطق الاقتصادية، قطر): عربي أولًا مع
تكافؤ كامل للإنجليزية، مصمَّم للجوال، ويعمل دون اتصال بعد أول زيارة.

> **تنبيه.** هذا نموذج تجريبي للعرض والمراجعة، وليس خدمة رسمية. جميع الشركات والقطع والمبالغ والتواريخ
> الظاهرة فيه بيانات توضيحية. تسجيل الدخول والدفع والتوقيع الإلكتروني وجلب البيانات الحكومية كلها
> **محاكاة** لا تتصل بأي نظام، ولا يغادر الجهازَ شيءٌ مما يُدخَل. العلامة المستخدمة في التطبيق علامة أصلية
> أُعدّت لهذا النموذج وليست شعار «مناطق».

## الفكرة

التطبيق ليس كتالوجًا من خمسين نموذجًا؛ بل رفيق لرحلة واحدة (الانضمام ← العقد ← البناء ← التشغيل)
**يعرف دائمًا الخطوة التالية للمستثمر**. وتلتزم كل شاشة فيه بست قواعد:

1. **خطوة تالية واحدة واضحة.** زر أساسي واحد في كل شاشة.
2. **مرة واحدة فقط.** لا يُسأل المستثمر عمّا تملكه الدولة أصلًا؛ ويُعرض ما جُلب عنه مع مصدره («جلبناها عنك»).
3. **الحالة ظاهرة دائمًا.** كل طلب يبيّن «عند مَن الآن؟» وعدّاد معيار الخدمة.
4. **كل وثيقة قابلة للتحقق.** مولَّدة وموقَّعة إلكترونيًا وبرمز QR، في محفظة واحدة.
5. **الهدوء.** لون تأكيد واحد، وخطوط شعرية بدل الظلال، ومساحات رحبة.
6. **الصدق.** معايير الخدمة موسومة بأنها استرشادية، والبيانات التجريبية موسومة بأنها توضيحية.

## ما الذي يتضمنه

| القسم | المحتوى |
|---|---|
| الرئيسية | بطاقة «الخطوة التالية»، شريط الرحلة بمحطاتها الأربع، الطلبات الجارية، المستحقات، الاختصارات |
| الخدمات | الخدمات الخمسون مرتبةً بحسب الرحلة مع بحث عربي وإنجليزي، وصفحة لكل خدمة بعناصرها الأربعة المنشورة: من يطلبها وكيف، ما تحتاج إليه (وما تجلبه بنفسها)، معيار الخدمة، ما يتسلّمه المستثمر |
| طلباتي | خط زمني حيّ لكل طلب مبني على مسار العمل الفعلي للخدمة (575 خطوة في 50 مسارًا)، مع الجهة الحائزة للطلب وعدّاد المعيار والإجراء المطلوب |
| المناطق | المناطق الثلاث عشرة على خريطة تخطيطية، وصفحة لكل منطقة، والحلول الخمسة بأسعارها المنشورة |
| حسابي | ملف الشركة الموثّق، القطع والعقود، محفظة الوثائق والتصاريح، المدفوعات، الفريق والمفوّضون، الإعدادات، الدعم |

وتعمل الرحلات الأربع ذات الأولوية من بدايتها إلى نهايتها:

1. **من الاستفسار إلى عقد موقَّع** — فحص الأهلية، طلب الأرض، التقييم، العرض الرقمي والدفع، توقيع العقد، التسليم.
2. **من التسليم إلى منشأة عاملة** — شهادة عدم الممانعة، رخصة البناء، الدفاع المدني، كهرماء، في خط زمني واحد.
3. **الإيجار والتجديد والتحصيل** — الدفع بنقرتين، الإيصال الفوري، عرض التجديد قبل الانتهاء.
4. **طلب خدمة داخل المنطقة** — بلاغ صيانة بصورة وموقع، تصريح دخول رقمي، بلاغ طارئ.

## دفتر السكتشات

مجلد [`docs/sketches`](docs/sketches) يضم الرسومات اليدوية الأولية للتصميم (ستة عشر لوحًا): الفكرة، رحلة
المستثمر، خريطة التطبيق، والشاشات والرحلات الرئيسية، مع ملاحظات تشرح قرارات التصميم. الصور الجاهزة في
`docs/sketches/png`، ومصادرها في `docs/sketches/boards`، وأداة الرسم موثّقة في `docs/sketches/kit/README.md`.

## ملاحظة عن ملفات البيانات

ملفات المحتوى المستخرَج من الدليلين (`data/source`) والبيانات المولَّدة منها (`src/data/generated`) والنسخة
الجاهزة ذات الملف الواحد (`preview`) **غير مضمَّنة في هذا المستودع** ما دام عامًّا، إلى أن يقرّر مالك المشروع
نشرها. ومن دونها لا يكتمل البناء؛ فتُضاف هذه المجلدات إلى نسخة العمل قبل التشغيل.

## التشغيل

يتطلب Node.js 22 أو أحدث.

```bash
npm install          # تثبيت الاعتماديات
npm run dev          # خادم التطوير
npm run build        # نسخة متعددة الملفات (PWA) في dist/ تصلح لأي استضافة ثابتة
npm run build:single # ملف HTML واحد مكتفٍ بذاته في preview/index.html
npm run typecheck    # فحص الأنواع
npm test             # الاختبارات الوحدوية
npm run e2e          # اختبارات المسارات الكاملة (تعمل على preview/index.html)
npm run check        # كل ما سبق
```

الملف `preview/index.html` يُفتح مباشرة في المتصفح أو من الجوال دون خادم.

### روابط العرض

يمكن فتح التطبيق في حالة محددة بإضافة معاملات إلى الرابط قبل علامة `#`:

| المعامل | القيم | الأثر |
|---|---|---|
| `demo` | `tenant` · `prospect` · `guest` | ملف العرض: مستأجر قائم، مستثمر جديد، زائر |
| `lang` | `ar` · `en` | اللغة |
| `theme` | `light` · `dark` · `auto` | المظهر |
| `text` | `0` إلى `3` | حجم الخط |
| `speed` | رقم | سرعة المحاكاة (1 = الإيقاع العادي) |
| `reset` | `1` | إعادة ضبط بيانات العرض |

مثال: `preview/index.html?demo=tenant&lang=en#/requests`

## البنية

```
src/
  app/        التوجيه، اللغة والتنسيق، المخزن، المظهر
  design/     نظام التصميم: الرموز (tokens) والمكوّنات والرسوم الخطّية
  data/       أنواع البيانات والبيانات المولَّدة (generated/) ودوال الوصول إليها
  domain/     المنطق الصِّرف: محرّك مسارات العمل، زمن المحاكاة، الأهلية، البحث…
  state/      بيانات العرض، وكل ما يغيّر الحالة (actions)، والمحدِّدات (selectors)
  features/   الشاشات: الترحيب، الرئيسية، الخدمات، بدء الخدمة، طلباتي، المناطق، الحساب، المحفظة، المدفوعات، الرحلات المخصّصة
data/source/  مصادر البيانات (الخدمات الخمسون، البيانات الوصفية، المناطق، المعرفة)
scripts/      بناء البيانات والرسوم والأيقونات ولقطات الشاشة
tests/        اختبارات وحدوية (Vitest) ومسارات كاملة (Playwright)
docs/         دفتر السكتشات
```

التقنيات: React 19 و TypeScript (الوضع الصارم) و Vite، دون مكتبة واجهات جاهزة. الأنماط بـ CSS Modules فوق
رموز تصميم (CSS custom properties)، وبخصائص منطقية تجعل الاتجاهين (RTL/LTR) يعملان من الشيفرة نفسها.

## البيانات ومصدرها

- **محتوى الخدمات** مأخوذ من «دليل الخدمات» و«دليل أتمتة الخدمات والربط» (الإصدار 4.1، أكتوبر 2026). معايير
  الخدمة والمستويات المستهدفة **استرشادية** بانتظار خط الأساس للمرحلة صفر، والأمثلة العملية توضيحية، وبعض
  التكاملات غير قائم بعد؛ والتطبيق يُظهر ذلك حيثما عُرضت.
- **البيانات الوصفية للتطبيق** (التسمية المبسّطة لكل خدمة، نموذج طلبها، ما يُجلب تلقائيًا، الإجراءات المطلوبة
  من المستثمر في أثناء الطلب) أُعدّت لهذا النموذج استنادًا إلى الدليلين، وهي في `data/source/meta`.
- **المناطق**: الأسماء والمساحات والأسعار المنشورة من الدليلين. مواقع المناطق على الخريطة تقريبية، والخريطة
  تخطيطية (حدود قطر من Natural Earth، ملكية عامة). مخططات القطع وتوافرها بيانات توضيحية.
- **قائمة الأنشطة** في فحص الأهلية توضيحية؛ فالدليل يصف الفحص ولا ينشر القائمة.

يُعاد توليد بيانات التطبيق بالأمر `node scripts/build-data.mjs`، وهو يتحقق من سلامتها (اكتمال الخدمات
الخمسين، صحة المراجع، وصول كل مسار عمل إلى نهايته).

## ما الذي يُحاكى

| في الخدمة الفعلية | في هذا النموذج |
|---|---|
| الدخول عبر نظام التوثيق الوطني «توثيق» | اختيار ملف عرض؛ لا تُطلب أي بيانات دخول |
| جلب السجل التجاري والمفوّضين عبر منصة تبادل البيانات الحكومية | بيانات شركة توضيحية |
| الدفع عبر بوابة الدفع الإلكتروني الحكومية | ورقة دفع تجريبية؛ لا تُطلب بيانات بطاقة ولا يُخصم شيء |
| التوقيع الإلكتروني والتحقق عبر «تصديق» | توقيع بالإصبع ورمز تحقق تجريبيان |
| مرور الأيام وعمل الجهات | ساعة محاكاة: يوم العمل الواحد بضع ثوانٍ، مع زر لتقديم الزمن |
